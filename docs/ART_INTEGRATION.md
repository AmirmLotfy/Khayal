# Authored cast integration

The renderer supports finished Blender layers without changes to gameplay. Each cast uses `public/assets/cast/KIND/manifest.json` and PNGs generated by tools/blender/render_silhouettes.py. Add its lower-case identifier to the `cast` array in public/assets/cast/index.json only after review. Allowed identifiers currently used by gameplay:camel,cat,goha,boat,croc,afreet,mesaharati. Naddaha remains an asset-only delivery.

All parts share the same2048pxcamera framing. Each part specifies its PNG filename and normalized pivot[x,y]. Prepare separate named geometry/cuts in Blender; the exporter validates object names. Preview and correct pivots before declaring an asset articulated. The runtime loads a reusable1024px texture for each part, punches tiny interior perforations only in solid regions, then creates instances with independent pivots and depth blur. Original code silhouettes remain the explicit development fallback until the reviewed asset is listed.
